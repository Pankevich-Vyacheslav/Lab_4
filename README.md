# Висновок

Під час виконання лабораторної роботи було досліджено, реалізовано та протестовано алгоритми створення й обробки хеш-таблиць із використанням роздільних ланцюжків (Separate Chaining) та відкритої адресації (Open Addressing). Для послідовності із семи слів варіанта №15 було визначено числові ключі та обчислено хеш-значення за методами ділення і множення.

Шляхом ручної побудови та графічної візуалізації досліджено особливості розміщення елементів у чотирьох хеш-таблицях і способи розв'язання колізій. Також було розроблено та протестовано програмні реалізації алгоритмів мовою Python. Результати програмного виконання повністю збіглися з результатами ручної побудови.

Порівняльний аналіз показав, що для заданої послідовності слів найменшу середню кількість порівнянь під час успішного пошуку забезпечив метод ділення - 1,14 для обох способів хешування. За методом множення цей показник становив 1,29 для роздільних ланцюжків та 1,43 для відкритої адресації. Максимальна кількість порівнянь у всіх досліджених таблицях дорівнювала 2.

Таким чином, було набуто практичних навичок побудови хеш-функцій, створення й візуалізації хеш-таблиць, розв'язання колізій та аналізу ефективності пошуку елементів. Отримані результати підтвердили, що ефективність хешування залежить від вибору хеш-функції, способу обробки колізій та особливостей вхідних даних.
